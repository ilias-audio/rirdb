rirdb / Data files

Data files

Everything on this site is also available as plain files for scripts and notebooks: the catalogue, the spaces, each dataset's analysis, the download locks and manifests, and the per-IR metrics.

These files hold metadata and values derived from the audio, never audio. The audio stays with its original host, and each dataset's own licence governs it. A licence for rirdb's own code and catalogue has not been chosen yet: see About.

snapshots/metrics_core/<id>.parquet

One row per analysed IR, sorted by ir_id; metrics stored as 32-bit floats. The parameters, flags and grades are explained in the glossary. A value whose valid_* column is false is out of the ISO validity range: keep it out of statistics. Only T30 has valid_* columns here: the per-band edt_<band> and c80_<band> columns and sti also hold values outside the validity range, and the snapshots cannot tell them apart. For those, use the rirdb dev query views, which have valid_edt_*, valid_c80_* and valid_sti. The *_mid columns hold a value only where both the 500 Hz and the 1 kHz octave are valid.

The snapshots are exported from the corpus view, which has no dup_of column, so they still hold the {{ num.n_duplicates | int }} exact duplicate copies{% if num.dup_by_ds %} ({{ num.dup_by_ds }}){% endif %}; reports/corpus/duplicates.csv lists them by file. duration_s is the length analysed, after the onset is cut, not the length of the file. The file length (duration_raw_s) and the per-band edc_mode_* columns are only in the rirdb dev query views.
