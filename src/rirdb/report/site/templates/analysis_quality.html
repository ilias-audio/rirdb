Before any number is trusted, rirdb checks that each file is a usable impulse response: no sweep left over from the measurement, no hum, no gaps, a steady noise floor, and content up to the frequency the file claims. This page shows what the checks look for and how often each one fires in each dataset.

What the checks look for

Two sets of checks raise flags. The analyzer flags properties of the file and of the decay (clipping, short files, no noise floor, curved decays and so on). The signal audit runs afterwards on the same onset-cropped channel and asks whether the file is an impulse response at all: it looks for straight time-frequency ridges (sweep residue), sustained spectral lines (hum, birdsong, tones), envelopes that do not decay, runs of exact zeros, a noise floor that is not steady, and a spectrum that stops well below the file's Nyquist frequency. The audit covered {{ integrity.audited | int if integrity else "–" }} IRs.

A flag describes an IR; it does not delete it. Only the four content flags take an IR out of the clean measured rooms, because the file then holds something other than a room decay. Counts below are over the {{ n_ok | int }} analysed IRs of {{ n_datasets }} datasets.

Exact duplicates

Two IRs are duplicates when their decoded samples are identical (same SHA-1 of the sample data, whatever the file name or format). The de-duplicated view corpus_dedup keeps one IR of each group and marks the others with dup_of: {{ n_dup | int }} copies across the corpus. Every corpus figure, and every training or evaluation split built on rirdb, should use that view.

Left out: repeats

Many datasets publish the same position in several formats (OpenAIR's B-format and its mono copy, for example). Only the preferred representation counts, so a position is not counted twice. Exact duplicate copies are left out for the same reason.

Kept: everything else

Signal, decay and spatial flags stay in. The validity rules already drop the values a short file or a high noise floor cannot support, and the flags are there to filter on when a property matters for a use: an unsteady noise floor for noise studies, an upsampled file for bandwidth.
