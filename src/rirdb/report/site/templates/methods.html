From registry to report

Each step is a command run on QMUL's Apocrita cluster: the rirdb commands inside a SLURM job (sbatch jobs/quick_cpu.sh pixi run rirdb …), the download script as a SLURM job of its own, and the analysis and audit scripts by submitting SLURM arrays. Each step writes files the next one reads, and the small ones are committed to the repository, so every number on this site can be traced back to a file.

Glossary

Every term the dataset and analysis pages use. Column names are those of the per-IR views of rirdb dev query. The metrics snapshots keep a subset of them: duration_raw_s, for one, is not in them, and their duration_s is the length analysed, after the onset is cut.

Acoustic parameters

Single numbers ending in _mid are the mean of the 500 Hz and 1 kHz octave values when both are valid. Every decay time, clarity and definition value also exists per octave band from 63 Hz to 8 kHz and broadband (t30_500, c80_bb, …), each with its validity flag.

Grades

Each analysed IR gets one grade from the octave bands in which its decay times are valid. Validity needs enough decay range above the noise floor: 20 dB for EDT, 35 dB for T20 and 45 dB for T30.

Subsets

The corpus statistics use nested subsets. Each one keeps part of the one above it. The clean measured rooms subset is the default for anything that describes real rooms: it keeps one representation per position, drops exact duplicates and drops IRs with content flags.

Index fields

The fields that decide which IRs to use. They are columns of the rirdb dev query views (corpus by default; dup_of only in corpus_dedup and clean_rooms). The metrics snapshots have all of them except dup_of and edc_mode_<band>, and of the validity flags only valid_t30_<band>.

Querying the tables

rirdb dev query runs SQL predicates over the per-IR views (DuckDB over the Parquet tables). The default view is corpus; --view corpus_dedup adds dup_of, and --view clean_rooms is the clean measured rooms subset. It prints at most 50 rows unless --limit says otherwise; --limit 0 returns every row. Examples (more in the README); the third lists every exact duplicate copy with the record it copies:
