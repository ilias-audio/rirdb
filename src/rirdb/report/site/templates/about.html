About rirdb

rirdb is a consolidated, checked catalogue of public room impulse response datasets, with one uniform acoustic analysis of the IRs it could download{% if num.n_sub %} (of a fixed subsample for the {{ num.n_sub }} largest datasets){% endif %}. It exists so that anyone looking for reverb data can find it, judge it and fetch it without opening every archive first.

What rirdb is, and why

Public room impulse response datasets are scattered across lab websites, Zenodo records, GitHub repositories and archives that sometimes disappear. Each describes its IRs in its own way, with its own licence, file layout and quality. Choosing one usually means downloading and inspecting several.

rirdb puts them in one place. It catalogues {{ num.n_all | int }} datasets: {{ num.n_registry | int }} in its registry and {{ num.n_survey | int }} more found on the web. For each it records where to get it, what it holds and what its licence allows. It downloads {{ num.n_lock_ds | int }} of the registry datasets with checksums and analyses their IRs with the same methods (ISO 3382-1/-2 and IEC 60268-16): {{ num.n_irs_analysed | int }} IRs from {{ num.n_analysed | int }} datasets so far{% if num.n_sub %}, every IR of {{ num.n_full }} of them and a fixed subsample of the {{ num.n_sub }} largest{% endif %}. The result can be searched by what you need: a kind of space, a decay time, a capture format, a licence.

It was built for research on feedback delay network (FDN) reverberation, where it supplies training data and target room responses, and it is shared so that others need not repeat the work.

Who

rirdb is made by Ilias Ibnyahya, a PhD researcher at the Centre for Digital Music (C4DM), Queen Mary University of London, as part of his doctoral work on FDN reverberation. Source code and history: {{ REPO_URL | replace("https://", "") }}.

The catalogue is to be presented as the Reverb Dataset Field Guide at DMRN+21, the Digital Music Research Network workshop at King's College London on 11 December 2026, if the abstract is accepted. The Field Guide is on this site.

How to cite

Please cite every dataset you use: each dataset page gives its paper, DOI and licence. If rirdb's catalogue or analysis helped, please cite rirdb too.

rirdb has no DOI yet. Until it has one, cite the GitHub repository and the build date of the version you used. A Zenodo DOI for the code and the derived data is planned (hosting plan); this page will give it once it exists.

Credits

The data is the work of the authors of every dataset listed here, who measured the rooms and shared the results. Every dataset page names them through the dataset's paper, homepage and DOI.

This repository started as a fork of RoyJames/room-impulse-responses, a community list of public RIR datasets; rirdb adds the registry, the checks and the analysis.

Each dataset keeps its own licence. rirdb relicenses nothing and hosts no audio: it links to the original sources, and each dataset page explains, in plain words, what its licence allows.

Contributing

A dataset that is missing. Add a folder registry/<id>/ with a dataset.yaml and open a pull request. Give the source (Zenodo record, URL or repository), the licence, how many IRs and spaces it has, and the channel format.

A mistake. A wrong licence reading, a dead link, a miscounted dataset or a space in the wrong category: open an issue with a link to the evidence.

A dataset author? Corrections and updated links are especially welcome, as are notes on how your IRs were measured.
